# BORJÃO FITNESS — BUILD 03 / ARTE TRATADA

Pacote de mídias para **integração na Home já construída**, não para publicar os mockups como imagens chapadas.

## O que vem neste pacote
- 11 imagens WebP para a montagem desktop das seções 01, 02, 03, 04, 05, 06, 08 e 09.
- 2 logos recortadas da base existente e não recriadas nesta rodada.
- `MANIFESTO_ASSETS_BUILD03.json` com nome, proporção, origem, uso e hash de cada arquivo.
- `PROMPT_WORK_BUILD03.txt` com a execução operacional no GitHub.

## Critérios obrigatórios
- Copiar `public/assets/borjao/final-v1` para o projeto, sem renomear os arquivos.
- **Não** incluir texto, preço, badge, mapa clicável ou CTA dentro das imagens.
- Desativar os placeholders de mídia para os slots integrados, mantendo geometria/diagonais aprovadas.
- Não sobrepor um segundo grid/diagonal a uma imagem que já contém esse recorte; conferir a montagem por comparação lado a lado.
- `EM BREVE` é texto HTML sobre a foto. O mapa pode ser ilustrativo mas o botão Traçar rota deve usar a URL funcional.
- Não incluir o sapinho com fundo preto: a fonte da imagem não era um recorte transparente confiável; preferir mascote validado e recortado em PNG separado, preservando a identidade.
- A Home demonstra uma proposta **conceitual**; as composições não comprovam que locais/fachadas/pessoas e obra estejam exatamente como nas fotos. Antes da publicação comercial, conferir com a equipe Borjão e usar uma identificação discreta de arte ilustrativa quando aplicável.
- Responsividade mobile exige uma rodada própria de arte direcionada. Evitar crop arbitrário que esconda partes centrais. Não declarar o mobile homologado pela simples integração desktop.
